# lunchpaad

Lunchpadd - AI-Powered Website Builder

A modern, responsive landing page for an AI-powered website builder platform built with React, TypeScript, and Vite.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## ✨ Features

- 🎨 Premium, modern design with glassmorphism and refined color palette
- 📱 Fully responsive for mobile, tablet, and desktop
- ⚡ Built with Vite for lightning-fast development
- 🔷 TypeScript for type safety
- 🎭 Smooth animations and transitions
- 🧩 Component-based architecture with organized folder structure

## 🛠️ Tech Stack

- **React 18.2** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Lucide React** - Icon library
- **CSS3** - Styling

## 📁 Project Structure

```
src/
├── components/
│   ├── layout/          # Header and Footer
│   ├── pages/           # Legal and Auth pages
│   ├── sections/        # Landing page sections
│   └── ui/              # Reusable UI primitives
├── App.tsx              # Main app component
├── main.tsx             # Entry point
└── index.css            # Global styles and design system
```

## 🎨 Sections

1. **Header** - Sticky glassmorphic navigation with mobile dropdown
2. **Hero** - AI prompt input box with animated placeholders & suggestions
3. **Stats** - Key platform metrics
4. **Features** - 8 AI-powered features with modern cards
5. **How It Works** - 3-step creation process
6. **Pricing** - Free, Pro, and Enterprise tiers
7. **Website Types** - 12 website templates & categories
8. **CTA** - Engaging conversion section
9. **Footer** - Brand links, legal policies, and contact info
